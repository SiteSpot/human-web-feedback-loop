# Research notes, October 2026

What the experimentation and CRO platforms say about autonomous optimisation loops, and the statistics sources behind the skill's rules. Kept so the skills can be checked and updated. Vendor lift figures are self-reported throughout. Where a page could not be fetched directly, the source is flagged.

**Synthesis.** Everyone has converged on a four-to-six step cycle with the same shape. They differ on (a) the autonomy default: fully automatic with optional human (Fibr, Evolv, Webflow, Unbounce) vs an explicit dial with a conservative default (Wingify, Statsig) vs propose-and-approve only (Convert, Kameleoon, Contentsquare, Optimizely staging); (b) where the human gate sits: before launch, at rollout review, or only at the strategy and guardrail level; (c) statistical transparency: engineering-side vendors name sequential testing, CUPED, SRM and FDR, marketing-side vendors mostly don't or lean on bandits that explicitly de-prioritise significance; (d) who calls winners: Convert refuses, Fibr sets them, bandits never declare one, Wingify measures against a permanent holdout. Only Statsig, Convert and Optimizely describe agent safety engineering (permission-scoped tools, create/update separation, audit logs, behavioural guardrails).

Recurring words worth matching: *agentic, always-on, continuous, autopilot vs co-pilot, guardrails, approval gate, holdout, kill switch, synthetic visitors, headless, virtual teammate, self-optimising website.*

## 3. AB Split Test facts the skills rely on (checked against the code, 22 Oct 2026)

The skills keep product detail in `skills/website-optimisation-loop/references/wordpress.md` and `cloud.md`, and defer to the MCP tool descriptions. These are the facts those files depend on.

- Decision thresholds (plugin `includes/statistics.php`, mirrored in Cloud `packages/stats`): every variation at least 50 visits (`ab_min_visits_for_winner`), 25 conversions per variation (`abst_min_conversions_for_winner`, multiplied by the variation count), probability to be best at least 95% (site setting), expected loss under `abst_expected_loss_threshold`. `blocked_by` names which of `visits`, `events`, `probability`, `loss` is blocking. No minimum runtime and no sample-ratio check exist in either edition.
- WordPress `create-test` statuses: `idea`, `draft`, `publish`, `pending`, `complete`. `update-test-status`: `publish` starts or resumes, `draft` pauses, `complete` ends. Test types: `magic`, `ab_test`, `css_test`, `full_page`. Winner `mode`: `notify`, `autocomplete`, `thompson`, `autooptimize` (magic only). The create-test description tells agents to ask the user for the conversion goal first. Selectors and previews via `?abhash=1`. Connection via the WordPress MCP Adapter and an Application Password.
- AB Split Test Lite 1.0.0 registers six abilities: `create-test`, `list-tests`, `get-test-details`, `get-test-results`, `update-test-settings`, `update-test-status`. One variation per test; page-visit and element-click goals; heatmaps in the admin but not exposed as abilities. Its readme says unlimited tests and no traffic meter; the absplittest.com pricing page says one active test, one goal and three-day heatmap retention. These need reconciling.
- The paid plugin also registers goals, audiences, heatmap and page-analytics, site-content, post and post-meta, builder-context, settings and MCP audit-log abilities. Learnings (`includes/learnings.php`) are recorded on completion and shown in the Optimization Hub, but no ability reads them.
- Cloud (`https://cloud.absplittest.com/mcp`, bearer key): `create_test` creates a draft unless `start: true`. Statuses: `draft`, `running`, `paused`, `complete`. Types: `full_page`, `magic`, `css`, `onpage`. Winner `mode`: `report` (default), `winner`, `thompson`, `autooptimize` (magic only). `get_results` returns `best`, `probability`, `winner`, `blocked_by`, `expected_loss`, `min_conversions`, `likelyDuration`, `likelyVisitors`, with device and audience breakdowns. Verdicts every 15 minutes or on `recompute`. Auto-optimise: `propose_next_round`, `create_next_round`; round limit is a site setting (default 5). Prompt `write_test_brief`; resource `abst://tests/{id}/results.csv`. One-time allowance of 100,000 page views per account; signups via the waitlist on absplittest.com/cloud.
